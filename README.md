# Gogigrav

Нативный Git-клиент на Go и gogpu/ui. За основу интерфейса взят Embegrav. Слева находится история коммитов, справа — сведения о выбранном коммите или рабочие изменения. Разделитель между панелями можно перетаскивать.

## Запуск

Из каталога проекта в PowerShell:

```powershell
.\gogigrav.exe D:\git\embegrav
```

Приложение принимает несколько путей. Если передать родительский каталог, Gogigrav найдёт репозитории в его непосредственных подкаталогах и добавит их в переключатель. При запуске без аргументов приложение откроет текущий репозиторий, последний использованный репозиторий или форму открытия.

## Работа с репозиторием

- Переключатель в левом верхнем углу открывает недавние репозитории. В поле поиска можно вставить путь к репозиторию или папке. Для папки без Git появится **Initialize**, а для пустой папки — варианты клонирования одноимённых репозиториев GitHub, доступных через `gh`. Правый щелчок по переключателю или репозиторию в списке открывает меню пути.
- В меню веток можно искать и отмечать несколько веток в дереве **Local** и **Remote**. Переключатель **Remote** скрывает удалённые ветки в меню и в истории. В истории доступны поиск по загруженным коммитам и **Load more**. По умолчанию загружается до 300 коммитов. Щелчок по строке открывает сообщение, автора, родителей и дерево изменённых путей. Из панели коммита можно создать ветку или тег.
- Строка **Uncommitted Changes** появляется при наличии изменений и открывает индекс и рабочее дерево. Выберите файл и нажмите **Stage** или **Unstage**, либо добавьте все изменения через **Stage all**. Для коммита введите сообщение и нажмите **Commit**. Доступен **Amend**.
- Столбец **Diff** показывает число изменённых файлов, добавленных и удалённых строк. Перетаскивание разделителя меняет ширину столбца, двойной щелчок сбрасывает её. Правый щелчок по заголовку открывает меню видимости столбцов.
- В режиме **Unified** описание коммита или рабочее дерево раскрывается прямо под своей строкой истории. Повторный щелчок по строке или кнопка **×** сворачивает панель. В режиме **Split** детали открываются сбоку.
- Имя текущей ветки в строке состояния открывает поиск по локальным веткам и переключает рабочую ветку. Рядом с upstream кнопки со счётчиками запускают **Push** и **Pull**.
- Иконки на верхней панели открывают поиск и меню веток, запускают fetch с prune, pull и push. Обычные **Pull** и **Push** используют upstream. Стрелки рядом с ними открывают выбор remote, ветки и параметров. **Pull** учитывает настройки Git, в форме можно выбрать rebase. В меню **Remotes** можно добавить remote или открыть его URL для редактирования.
- Меню **Stashes** открывается с тулбара и по счётчику в строке состояния. В нём можно создать stash, найти сохранённый, применить его, выполнить **Pop**, создать из него ветку или удалить его с подтверждением.
- Для репозитория без remote кнопка **Publish** предлагает создать приватный или публичный репозиторий GitHub, добавить `origin` и отправить коммиты. Имя владельца может быть именем организации.
- Шестерёнка **Settings** открывает модальное окно с настройками истории, отображения, темы и fetch. Параметры применяются сразу после изменения. **Colour theme** переключает DevTools и DevTools Dark или импортирует цвета интерфейса из темы VS Code. В разделе **Repository** можно изменить локальные Git-имя и email. На Windows настройки сохраняются в `%APPDATA%\gogigrav\settings.json`.
- **Ctrl+O** открывает форму выбора каталога, **Ctrl+F** переводит фокус в поиск, **F5** перечитывает состояние Git. После действий из интерфейса данные обновляются автоматически.

## Просмотр файлов и диффов

Двойной щелчок по файлу открывает дифф. В истории он показывает изменения относительно первого родителя коммита, в **Staged changes** сравнивает HEAD с индексом, а в **Changes** — индекс с рабочим файлом. Gogigrav определяет язык по имени файла и подсвечивает код с помощью Chroma.

В просмотрщике выберите **Unified** или **Split** для диффа либо переключитесь на файл до изменения, файл выбранной ревизии или рабочую копию. **Wrap** переносит длинные строки, **Files** открывает дерево соседних файлов, **Esc** возвращает к истории.

Правый щелчок по файлу открывает меню просмотра и сравнения с рабочей копией. Для файлов и папок доступны копирование относительного и абсолютного пути и переход в проводник. В деревьях рабочих изменений меню также позволяет добавить путь в индекс, убрать его из индекса или сбросить изменения с подтверждением.

## Git и GitHub CLI

Для локальной работы нужен `git` в PATH. GitHub-функции используют `gh` и его обычную сессию. В Windows приложение также ищет CLI в каталогах `GitHub CLI` внутри `%LOCALAPPDATA%\Programs` и `%ProgramFiles%`.

Для входа при пользовательской установке:

```powershell
& "$env:LOCALAPPDATA\Programs\GitHub CLI\gh.exe" auth login
```

**Settings → Check GitHub sign-in** показывает имя активного пользователя или сообщение CLI.

## Разработка

Перед первой сборкой выполните `./tools/prepare-wgpu.ps1` в PowerShell. Скрипт подготовит локальную копию wgpu v0.34.14 в `.deps` и применит профиль памяти Gogigrav. Готовый exe включает профиль.

На Windows при выборе Vulkan приложение использует блоки по 16 МиБ, порог отдельного выделения 8 МиБ и до 32 блоков на пул. Чтобы запустить со стандартным профилем wgpu (64 МиБ), задайте в PowerShell `$env:GOGIGRAV_VULKAN_MEMORY = "standard"` перед запуском. Для возврата к компактному профилю выполните `Remove-Item Env:GOGIGRAV_VULKAN_MEMORY` и перезапустите приложение.

Go-модуль подключает `github.com/gogpu/ui` через относительный `replace` на соседний каталог `../gogpu__ui-custom`. В этой рабочей области это отдельное рабочее дерево ветки `custom` репозитория `D:\git\gogpu__ui`. Изменения компонентов и тем делаются непосредственно в той ветке.

```powershell
go run . -theme "DevTools Dark" D:\git\embegrav
go test ./...
go vet ./...
go build -trimpath -ldflags "-H=windowsgui" -o gogigrav.exe .
```

Проверенная ревизия фреймворка — `e75405a` в локальной ветке `4gogigrav`. Для сборки на другой машине разместите checkout этой ревизии рядом с проектом под именем `gogpu__ui-custom` или измените относительный путь в `go.mod`. Интеграционные тесты Git используют временные репозитории.

Панель использует SVG из JetBrains Int UI. Поиск, обновление, настройки и стрелки поставляются в `gogpu/ui`. Остальные SVG встроены из `assets/intui` и распространяются по Apache 2.0. [IntelliJ Platform Icons](https://intellij-icons.jetbrains.design/)
