# File type icons

The icons, filename and extension mappings, and light and dark color palettes come from the complete icon set in [@pierre/trees 1.0.0-beta.6](https://github.com/pierrecomputer/trees), which Embegrav uses for its changed-files tree. The SVG symbols were converted to standalone SVGs and packaged with the mappings and palettes in `icons.json`.
